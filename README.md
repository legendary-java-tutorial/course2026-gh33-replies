# Угадай число

Игра в терминале и в браузере: компьютер загадывает число, вы угадываете.

Тема — «Лес» 🌲: ели, тропинки и совы.

## Режимы

| Режим | Диапазон | Подсказки | Победа |
|---|---|---|---|
| классический | 1–100 | больше / меньше | угадал! |
| трудный | 1–5000 | больше / меньше | угадал! |
| детский | 1–20 | бери больше / бери меньше | молодец, угадал! |

## Как запустить

`npm start` — играть, `npm test` — проверить тексты.
